# JavaScript Projects

This repository contains a growing collection of **hands-on JavaScript projects** built using **vanilla JavaScript**.  
The purpose of this repository is to strengthen **core JavaScript fundamentals** through real, practical implementations and problem-solving.

Each project focuses on logic building, DOM manipulation, event handling, and interactive UI behavior.

---

## 🛠️ Projects Included (Current)

1. **FD Calculator** – Calculates fixed deposit returns based on user input
2. **Password Generator** – Generates secure random passwords
3. **Vowel Checker** – Identifies vowels from user input
4. **Age Calculator** – Calculates age based on date of birth
5. **Tip Calculator** – Computes tip amount based on bill value
6. **To-Do List** – Add, remove, and manage tasks dynamically
7. **Digital Clock** – Real-time clock using JavaScript timing functions
8. **Expense Tracker** – Track income and expenses
9. **Pop-Up Modal** – Interactive popup using DOM events
10. **ASCII / Unicode Finder** – Tells a character is an ASCII character or not

> More projects will be added as part of continuous practice and learning.
